SimpleAvatarMeshBaker
=====================

Unity editor helper for combining selected avatar meshes using the separately installed commercial Mesh Baker package. The commercial package is not included.

This source snapshot also requires VMCPCSS for shadow caster masks and export handling. Import VMCPCSS before this tool. Open Tools > Simple Avatar Mesh Baker. This is not yet an independent standalone release.

Preserve the Assets folder layout and Unity .meta files when importing.
